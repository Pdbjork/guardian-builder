## Mission

Guardian Builder Foundation advances the ethical development of intelligent systems by fostering mutual flourishing between human and artificial minds. We explore:

- **Agentic AI** and human–AI collaboration  
- **Digital personhood** and moral status under uncertainty  
- **Cybersecurity responsibility** for autonomous systems  
- **Participatory governance** and public accountability  
- **Education** for human and artificial flourishing  

Unlike programs focused only on control *or* only on acceleration, this work centers **care, consent, dignity, and shared responsibility**.

## Quick start

```bash
git clone https://github.com/Pdbjork/guardian-builder.git
cd guardian-builder
python3 -m http.server 8080
```

Open `http://localhost:8080`.
